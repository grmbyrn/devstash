- 2026-07-24 — **Rate Limiting for Auth** (Completed). Added Upstash-backed rate limiting across the whole auth surface (brute force / credential stuffing / email-send abuse). New `src/lib/rate-limit.ts`: a lazy Upstash Redis client (`undefined`=unresolved / `null`=unconfigured) + a cached sliding-window `Ratelimit` per config, driven by a `RATE_LIMITS` table (`login` 5/15m, `register` 3/1h, `forgotPassword` 3/1h, `resetPassword` 5/15m, `resendVerification` 3/15m — mirrors the spec). `checkRateLimit(name, identifier)` returns `{ success, remaining, reset, limit }` and **fails open** (returns an `ALLOW_UNLIMITED` sentinel when Upstash is unconfigured *or* the `.limit()` call throws) so a Redis outage can never lock users out.
